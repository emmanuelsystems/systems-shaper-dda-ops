# Repo Boundary

`dda-agent-ops` remains the active DDA pilot repo unless explicitly replaced.

`systems-shaper-dda-ops` is a proposed operations repo for broader DDA / Codex workflow structure.

This repo may eventually hold reusable workflow rules, branch SOPs, verifier gates, and handoff templates, but it should not import or replace pilot artifacts without review.

## Current Boundary

- This repo is review-only.
- This repo is not accepted infrastructure.
- This repo does not replace `dda-agent-ops`.
- This repo does not claim Context Vault status.
- This repo does not enable automation.
- This repo does not promote skills or evals.

## Migration Boundary

Any migration from `dda-agent-ops` must happen through a reviewed source map, a scoped migration branch, and explicit human approval.
