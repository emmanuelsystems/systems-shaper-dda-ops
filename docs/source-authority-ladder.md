# Source Authority Ladder

Use the highest available source when making repo-local claims.

1. Reviewed GitHub artifact
2. Current run source-index
3. Linked issue / task with explicit status
4. Approved Notion / planning artifact
5. Drive source document or transcript
6. Slack coordination thread
7. ChatGPT / DDA working context
8. Unverified memory or recollection

## Conflict Rule

When sources conflict, Codex should name the conflict instead of averaging the claims.

## Missing Evidence Rule

When a source is unavailable, name the unavailable source and keep the claim held. Do not silently upgrade working context into durable truth.
